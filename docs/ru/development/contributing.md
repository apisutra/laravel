# Участие в разработке <a id="section-1"></a>

Используйте [окружение разработки и проверки](testing.md). Сохраняйте zero-config
defaults и явные overrides. Общие механизмы относятся к ядру.
Обновляйте обе языковые редакции и запускайте проверки затронутого поведения.
